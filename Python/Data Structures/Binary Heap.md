Куча, устроенная не как один массив-дерево (как binary heap), а как **лес биномиальных деревьев**, где биномиальное дерево порядка k построено рекурсивно: два дерева порядка k−1, одно становится ребёнком корня другого. 
Ключевое свойство — размер дерева порядка k строго равен 2^k, и в лесе может быть не больше одного дерева каждого порядка. 
Главная фишка — **merge (union) двух куч работает за O(log n)**, а не за O(n), как при слиянии двух binary heap. Слияние похоже на сложение двух двоичных чисел в столбик: деревья одного порядка "переносятся" в дерево следующего порядка (как перенос разряда). 
Именно на этой операции метод потенциалов раскрывается особенно наглядно: Φ = количество деревьев в лесе, и merge с "переносами" амортизированно дёшев, потому что каждый перенос уменьшает Φ на единицу, компенсируя свою стоимость.
